# soqreq デモ用チケット

このリポジトリはsoqreqのデモンストレーション用のチケット管理リポジトリです。

## デモ実施前の準備

soqreqワークフローのデモを動かす前に、以下のチケットをIssueとして起票してください。

### 起票するチケット

**タイトル:**
```
feat: 高額経費の二段階承認機能追加
```

**本文:**
```markdown
# 高額経費の二段階承認機能追加

## 背景・課題

現在の経費申請システムは、全ての申請が直属上司の承認のみで完結している。

しかし、高額な経費申請については、より上位の承認者による確認が必要である。
現状では10万円の申請も100万円の申請も同じ一段階承認で完結してしまい、
内部統制の観点から問題がある。

## 実現したいこと

申請金額に応じた二段階承認フローを導入したい。

### 承認ルール

- **10万円未満**: 直属上司の承認のみ（現行通り）
- **10万円以上**: 直属上司 + 部長承認
- **50万円以上**: 直属上司 + 役員承認

### 求める機能

1. 申請金額に応じて自動的に承認フローが決定される
2. 承認者は現在どの段階か、次は誰が承認すべきかが分かる
3. 申請者は承認の進捗状況が分かる
4. 既存の一段階承認はそのまま動作すること（後方互換性）

## 受け入れ基準

- 10万円未満の申請は、従来通り一段階承認のみで完了する
- 10万円以上の申請は、直属上司承認後に部長承認が必要になる
- 50万円以上の申請は、直属上司承認後に役員承認が必要になる
- 承認画面で、現在の承認段階と次の承認者が表示される
- 申請一覧で、承認の進捗状況が一目で分かる
- 既存の申請データに影響がない
```

## 使い方

Issueとして作業チケットを作成し、soqreqワークフローでの開発フローをデモンストレーションします。
